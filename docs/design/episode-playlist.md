## 概念

播放列表和剧集不是互斥的两种模式：

- **播放列表**：用户主动排的队列，可跨目录。
- **剧集**：当前文件所在目录里，按文件名识别出的系列。

一个列表里可以有若干部剧的文件。导航默认「有剧集则切集，否则切列表」。

## 现行行为（已完成）

| 项 | 行为 |
|----|------|
| 面板生命周期 | 侧栏不受底部控制栏 3 秒隐藏影响。`m_showControls` 只管控制栏、菜单栏、文件名、同步信息 |
| 位置 | 剧集左侧，播放列表右侧，可同时打开 |
| 开关 | 列表：底部按钮、播放菜单、`Ctrl+L`。剧集：剧集菜单、`Ctrl+E`；识别到剧集时自动打开 |
| Prev / Next | `playNext()` / `playPrevious()` 优先剧集，否则列表循环。`P` / `N` 同语义 |
| 专属切集 | `Ctrl+Shift+←` / `→` 只切集，不 seek |
| 连播 | 自然结束：有下一集则切集；否则推进播放列表。手动停止/切文件不连播 |
| 手动标志 | `playNext` / `playPrevious` / `playEpisode` / `playFromPlaylist` / `stop` / seek 会设 `m_isManualOperation` |
| 切集与列表索引 | `playEpisode` 若该集已在列表中，只更新 `m_currentIndex`，不自动往列表里塞 |
| 进度显示 | 剧集项可显示已看进度；列表项悬停显示百分比 |
| 文件名避让 | 左右面板打开时，文件名最大宽度减去面板宽度 |

Esc 只关菜单，不关侧栏。

## 实现约束（仍有效）

- 侧栏渲染必须在 `m_showControls` 判断块之外。
- 有剧集时底部 Prev/Next 的 tooltip 应为「上一集 / 下一集」，否则「上一个 / 下一个」。
- 自然结束连播走 `onStateChanged(Stopped)` → `m_pendingAutoAdvance`，不要在解码线程里直接 `openFile`。
- `m_isManualOperation` 必须在用户发起的停止和切换里置位，否则会误触发连播。
- 菜单项使用 `MenuId` 枚举，不要再加魔法数字。动态项用 `menuItemOffset`。
